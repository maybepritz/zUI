# История изменений

## 0.2.0 · Vega

Версия 0.1.1 не публиковалась: её изменения вошли в этот выпуск.

### Подбор стратегии

- «Подобрать» перебирает стратегии, начиная с избранных, останавливается на первой, с которой открывается всё, и включает обход. Если такой нет, включает ту, что открыла больше всего.
- Тест проверяет настоящий видеоузел YouTube у провайдера: кластер берётся из `redirector.googlevideo.com/report_mapping`.
- Адрес считается открытым, только если пришли первые 32 КБ ответа: так ловится обрыв соединения на 16–20 КБ.
- После мастера первого запуска подбор начинается сам.

### Главная

- Один переключатель обхода и список сервисов: видно, что открывается, а что нет.
- График задержки за сутки; время, когда zUI был закрыт, отмечено пунктиром.
- Если сервис перестал открываться, рядом появляется «Подобрать заново».
- Если обход не включился, причина видна на главной и во всплывающем окне.
- Без прав администратора zUI предлагает перезапуститься с ними.

### Запуск

- Подготовка идёт в фоне на новом экране: загрузка, итог проверки обновлений, затем вопрос о правах.
- Вопрос о правах можно отключить: «Настройки → Предлагать запуск от администратора».

### Надёжность

- Тест стратегий проверяет только сервисы, которые zapret может открыть.
- Повторная настройка DNS больше не теряет исходное состояние DoH.
- Повреждённые settings.json и statistics.json больше не перезаписываются: файл сохраняется рядом.
- Zapret и Telegram-прокси скачиваются через одну общую загрузку с GitHub.

### Прочее

- Статистика показывает результат последнего теста и историю событий.
- Спокойнее интерфейс: приглушённые цвета статусов и точка состояния.
- Убраны скрытые профили.
- Установщик Inno Setup; номер и имя выпуска он берёт из исходников.

## 0.1.0 · Lyra

### Стратегии

- Избранное с сохранением после перезапуска.
- Избранные стратегии отображаются первыми.
- Поиск по названию и имени файла без учёта регистра.
- Фильтр «Только избранное», счётчик результатов и сброс.
- Пояснения для пустого списка и отсутствующих результатов.

### Интерфейс

- Lucide-иконки в боковом меню.
- Прокрутка по всей области вкладки, включая свободное место по бокам.
- Фильтры расположены после блока тестирования.
- Обновлённый экран «Что нового»: название релиза, карточки изменений и закреплённая кнопка продолжения.

### Закрытие приложения

- Явный выбор между скрытием в трей и полным выходом.
- Запоминание действия с возможностью снова включить вопрос в настройках.
- При недоступном трее приложение остаётся видимым и позволяет выбрать выход.

### Локализация и код

- Fluent-каталоги русского и английского языков.
- Обнаружение языков, пользовательские пакеты и проверка переводов.
- Модульное разделение экранов, состояния, обработчиков и контроллеров.
- Общие компоненты карточек, страниц и модальных окон.
- Обновлённые README и документация подготовки релиза.

Профили временно скрыты в этом релизе; существующие данные сохранены.
