# История изменений

## 0.1.0 · Lyra

### Стратегии

- Избранное с сохранением после перезапуска.
- Избранные стратегии отображаются первыми.
- Поиск по названию и имени файла без учёта регистра.
- Фильтр «Только избранное», счётчик результатов и сброс.
- Пояснения для пустого списка и отсутствующих результатов.

### Интерфейс

- Lucide-иконки в боковом меню.
- Прокрутка по всей области вкладки, включая свободное место по бокам.
- Фильтры расположены после блока тестирования.
- Обновлённый экран «Что нового»: название релиза, карточки изменений и закреплённая кнопка продолжения.

### Закрытие приложения

- Явный выбор между скрытием в трей и полным выходом.
- Запоминание действия с возможностью снова включить вопрос в настройках.
- При недоступном трее приложение остаётся видимым и позволяет выбрать выход.

### Локализация и код

- Fluent-каталоги русского и английского языков.
- Обнаружение языков, пользовательские пакеты и проверка переводов.
- Модульное разделение экранов, состояния, обработчиков и контроллеров.
- Общие компоненты карточек, страниц и модальных окон.
- Обновлённые README и документация подготовки релиза.

Профили временно скрыты в этом релизе; существующие данные сохранены.
