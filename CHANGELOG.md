# История изменений

## 0.3.2 · Altair

Выпуск 0.3.1 не публиковался, его исправления вошли сюда.

### Исправлено

- После смены стратегии, включения обхода или перезапуска winws сервисы проверяются через пару секунд, а не через минуту.
- Пока новая стратегия не проверена, главная пишет «Проверяем» вместо сбоя, оставшегося от прошлой.
- Одна оборванная проверка больше не считается сбоем: zUI сразу пробует ещё раз и пишет «не открывается», только если не вышло оба раза.
- Задержка на главной — время соединения с сервером, а не ответа сайта. Цифры теперь близки к пингу в браузере и в звонке; первый час график показывает старые и новые значения вместе. Если сайт идёт через VPN-туннель, показывается время ответа сайта, как раньше.
- Экран изменений не показывается повторно при обновлении внутри одного выпуска, например с 0.3.0 на 0.3.2.

### Выпуск

- Для zUI.exe и архива GitHub выпускает подтверждение сборки, а в описании выпуска есть SHA-256 каждого файла.
- В README появился раздел о том, почему антивирусы ругаются на winws.exe и как проверить подлинность файлов.
- Установщик убран: zUI распространяется только архивом. Перед удалением папки `zUI.exe --cleanup` возвращает DNS и убирает автозапуск.

## 0.3.0 · Altair

### Главная

- График задержки за последний час по отдельным проверкам; суточный вид переключается рядом. Линии светятся в тёмной теме.
- У сервисов свои цвета: YouTube красный, Discord сине-фиолетовый.
- Под заголовком — стратегия и время последней проверки; плитки показывают задержку и состояние за сутки.
- Если проверка идёт при выключенном обходе, плитка говорит, открывается ли сервис без него.
- Причина «нет прав администратора» стоит отдельной плашкой с кнопкой перезапуска.

### Надёжность

- winws, Telegram-прокси и PowerShell привязаны к Job Object: при любом завершении zUI они останавливаются.
- Один экземпляр на папку данных; повторный запуск показывает уже работающее окно.
- «Запускать вместе с Windows», включённое от администратора, создаёт задачу планировщика с наивысшими правами: запрос UAC при входе не появляется.
- `zUI.exe --cleanup` возвращает DNS и убирает автозапуск; деинсталлятор вызывает его сам.
- У PowerShell и у обновления zUI появились таймауты: зависшая операция больше не блокирует выход и фоновые проверки.
- Остатки прерванной установки Zapret и прокси убираются перед новой попыткой; хранится одна резервная копия Zapret.
- Журнал пишется в `runtime/logs/zui.log`, туда же попадает текст паники.
- Обновления zUI и Zapret перепроверяются каждые 6 часов.

### Интерфейс

- Графитовая палитра, крупные заголовки страниц, заголовок окна в цвет темы.
- Настройки: пять строк в «Основном», остальное в «Дополнительно», служебное в «Помощи».
- Telegram: состояние и переключатель сверху, подключение в два шага.
- DNS: имя включённого пресета в заголовке, сброс на автоматический — ссылкой внизу.
- Окно больше не разворачивается на весь экран.

### Изменилось

- Пресет DNS «Comss One» заменён на «DNS AI». Уже применённый Comss продолжает работать и показывается своими адресами.
- Закрытие окна настраивается одним выбором: спрашивать, сворачивать в трей или выходить.

## 0.2.0 · Vega

Версия 0.1.1 не публиковалась: её изменения вошли в этот выпуск.

### Подбор стратегии

- «Подобрать» перебирает стратегии, начиная с избранных, останавливается на первой, с которой открывается всё, и включает обход. Если такой нет, включает ту, что открыла больше всего.
- Тест проверяет настоящий видеоузел YouTube у провайдера: кластер берётся из `redirector.googlevideo.com/report_mapping`.
- Адрес считается открытым, только если пришли первые 32 КБ ответа: так ловится обрыв соединения на 16–20 КБ.
- После мастера первого запуска подбор начинается сам.

### Главная

- Один переключатель обхода и список сервисов: видно, что открывается, а что нет.
- График задержки за сутки; время, когда zUI был закрыт, отмечено пунктиром.
- Если сервис перестал открываться, рядом появляется «Подобрать заново».
- Если обход не включился, причина видна на главной и во всплывающем окне.
- Без прав администратора zUI предлагает перезапуститься с ними.

### Запуск

- Подготовка идёт в фоне на новом экране: загрузка, итог проверки обновлений, затем вопрос о правах.
- Вопрос о правах можно отключить: «Настройки → Предлагать запуск от администратора».

### Надёжность

- Тест стратегий проверяет только сервисы, которые zapret может открыть.
- Повторная настройка DNS больше не теряет исходное состояние DoH.
- Повреждённые settings.json и statistics.json больше не перезаписываются: файл сохраняется рядом.
- Zapret и Telegram-прокси скачиваются через одну общую загрузку с GitHub.

### Прочее

- Статистика показывает результат последнего теста и историю событий.
- Спокойнее интерфейс: приглушённые цвета статусов и точка состояния.
- Убраны скрытые профили.
- Установщик Inno Setup; номер и имя выпуска он берёт из исходников.

## 0.1.0 · Lyra

### Стратегии

- Избранное с сохранением после перезапуска.
- Избранные стратегии отображаются первыми.
- Поиск по названию и имени файла без учёта регистра.
- Фильтр «Только избранное», счётчик результатов и сброс.
- Пояснения для пустого списка и отсутствующих результатов.

### Интерфейс

- Lucide-иконки в боковом меню.
- Прокрутка по всей области вкладки, включая свободное место по бокам.
- Фильтры расположены после блока тестирования.
- Обновлённый экран «Что нового»: название релиза, карточки изменений и закреплённая кнопка продолжения.

### Закрытие приложения

- Явный выбор между скрытием в трей и полным выходом.
- Запоминание действия с возможностью снова включить вопрос в настройках.
- При недоступном трее приложение остаётся видимым и позволяет выбрать выход.

### Локализация и код

- Fluent-каталоги русского и английского языков.
- Обнаружение языков, пользовательские пакеты и проверка переводов.
- Модульное разделение экранов, состояния, обработчиков и контроллеров.
- Общие компоненты карточек, страниц и модальных окон.
- Обновлённые README и документация подготовки релиза.

Профили временно скрыты в этом релизе; существующие данные сохранены.
