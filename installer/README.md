# Компактный установщик zUI

`zui.iss` предназначен для Inno Setup 7. Использует существующий release EXE;
Cargo автоматически не запускается. Ищет сначала
`target/x86_64-pc-windows-msvc/release/zUI.exe`, затем `target/release/zUI.exe`.

## Интерфейс

- Один русский экран: zUI Lyra, версия, путь и два переключателя.
- Установка по умолчанию в `%LOCALAPPDATA%\zUI`, без повышения прав.
- Ярлык на рабочем столе выключен по умолчанию, запуск после установки включён.
- При выключении запуска кнопка меняется на «Установить».
- После установки окно закрывается; выбранный запуск выполняется автоматически.
- Стандартный механизм Inno отвечает за прогресс, ошибки, отмену и удаление.
- Собственная графитовая разметка, Segoe UI, скруглённые блоки и светлая кнопка.
- Тёмное оформление независимо от темы Windows, чтобы палитра была предсказуемой.
- Оригинальный логотип zUI: `assets/app-logo.png` извлечён из 256px PNG внутри app/icon.ico без изменения пикселей.
- Enter запускает установку, Escape/«Отмена» используют обычное поведение Inno.
- Масштабирование размеров через ScaleX/ScaleY; кнопка передаёт действие штатному обработчику Inno.

## Упаковка

Из корня проекта:

```powershell
& 'C:\Program Files\Inno Setup 7\ISCC.exe' .\installer\zui.iss
```

Выход: `dist/zUI-0.1.0-Lyra-Setup.exe`. Для другой версии укажите
`/DMyAppVersion=0.1.1` перед путём сценария. Для конкретного бинарника используйте
`/DMyAppExe=...`. Номер должен соответствовать версии реально собранного приложения;
установщик не обновляет исходники и не пересобирает EXE. Имя Lyra пока задано в сценарии.

Если предыдущий Setup EXE открыт, его нельзя перезаписать. Закройте это окно
или задайте другое имя, например `/FzUI-0.1.0-Lyra-Setup-Redesigned`.
Не копируйте отдельные фрагменты сценария: открывайте полный `zui.iss`.
При сборке из другого расположения можно явно указать `/DRepoRoot=E:\zui`.

`AppId=zUI` сохранён из ранее предложенного сценария. Не меняйте идентификатор
между обновлениями, иначе Windows будет считать их разными установками.

ZIP с target в имени остаётся отдельным артефактом для встроенного обновления.
Установщик не заменяет формат архива и механизм обновления zUI.

## Данные и удаление

Сценарий не упаковывает runtime и не удаляет его рекурсивно. Настройки,
загруженные сервисы и снимок DNS сохраняются. Повышение прав для Zapret/DNS
остаётся обязанностью приложения.

Перед удалением следует выйти из zUI, остановить сервисы и восстановить DNS
в приложении. Автоматическая остановка сервисов и восстановление DNS через
uninstall-команду приложения пока не реализованы; не добавляйте удаление runtime
до появления такого сценария.

Компиляция проверена в Inno Setup 7.1.0. Сам новый установщик не запускался:
перед публикацией проверьте светлую/тёмную тему, DPI 100/150/200%, оба переключателя,
отмену, повторную установку поверх существующей версии и сохранение runtime.
