# План развития zUI

Работаем по одному небольшому шагу: Codex объясняет изменения и проверяет результат,
Артём пишет код. Реализация следующих пунктов начинается после проверки текущего.
Новые пользовательские строки добавляем в Fluent-каталоги en/ru; события проходят
через root/handlers, сценарии — через AppState, общая разметка — через components.

## Правила проверки каждого этапа

- cargo check --workspace --all-targets.
- Проверка переводов после добавления пользовательских сообщений.

- Отмечаем выполненные пункты только после проверки.

## Предыдущие идеи — сохранены для справки

Ниже исходный список. Многие пункты уже реализованы; это история идей, а не текущий план.

Мастер первого запуска. Выбор языка, прав, сервисов и автозапуска за несколько шагов.
Подпись exe. Уменьшает срабатывания SmartScreen и антивирусов, а для программы с WinDivert это частая проблема.
Тема по системной. Третий вариант в переключателе: «Как в системе».
Кнопка «Сообщить о проблеме». Собирает версию, логи и диагностику в один архив или в готовый текст для GitHub issue.
Системные уведомления Windows. Например, «Обновление готово» или «Стратегия сменена», когда окно свёрнуто.
Watchdog. Если winws упал, приложение перезапускает его и показывает уведомление (через ваш settings_status).
Список заблокированных нейросервисов с проверкой. ChatGPT, Claude, Gemini и т.д. с индикатором доступности, как в сервисах.
Автопереключение стратегии. Если сервис перестал открываться, приложение само запускает тест стратегий и меняет рабочую. Это полезно, когда провайдер меняет фильтрацию.
Периодический перетест стратегий. Например, раз в сутки в фоне, с уведомлением, если нашлась стратегия лучше.
Настройка уведомлений. Какие события показывать: ошибки, смена стратегии, обновления.
Управление hosts. Для обхода блокировок нейросервисов через hosts с резервной копией и откатом, как запасной вариант к DNS.
Статистика. Время работы, сколько раз менялась стратегия, когда был последний успешный тест.
Журнал изменений после обновления. Окно «Что нового» при первом запуске новой версии.
Перезапуск с правами администратора. Сейчас в настройках только подсказка «запустите от администратора». Можно добавить кнопку, которая перезапускает приложение с запросом UAC.
Проверка загрузок по SHA256. Особенно для zapret и TG WS Proxy, которые приложение скачивает само.
